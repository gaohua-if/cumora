## 正式实现验收条件

- 登录实际工作区后从配置入口打开四类页面，数据来自现有 Agent、群聊和服务端版本表；展示默认 Aida、本地执行位置和多 Agent 成员。
- 发布与升级 Agent、Skill、Bundle 后刷新读回固定引用；不同浏览器读取相同服务端配置。历史版本内容不可修改。
- 资源模式、语言优先级、身份与范围投影和原型一致；服务端校验不依赖前端状态。
- 保存失败保留草稿；修订冲突不覆盖他人的写入；撤销、未保存切换、Skill 导入成功/取消都不丢失选择上下文。
- 根任务与协作子任务固定已解析配置。配置升级前已创建及已领取任务继续使用旧快照；新任务使用升级后的配置。成员失效、授权撤销与 Runtime 变化继续实时阻断。
- 新迁移在真实隔离 Postgres 执行成功；现有迁移账本保持连续且 checksum 不变。运行相关集成测试、前后端类型检查及构建。
- 使用真实应用浏览器验证仅 Aida、多 Agent、配置保存/刷新、版本升级和生效预览，单独生成正式实现证据。
